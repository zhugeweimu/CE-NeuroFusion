# CE · 执行外骨骼（单包版）

> 让小模型（7B–14B）在 8K 上下文里干完本该 32K 才能干完的活。

**环境要求：Python 3.9+**
**本项目不含大模型**：先起一个 OpenAI 兼容的本地服务（llama.cpp / Ollama / LM Studio），
地址写进 `ce/config.json` 的 `llama_url`。没起也能启动，任务会返回「连不上模型服务」并给出排查步骤。

包内容是：执行器、自检工具、文档。
一个文件、一个配置、一条命令，跑起来就是一个本地 HTTP 服务。

```
ce/ce_tool.py            2100 行，纯标准库，零第三方依赖
ce/config.example.json   配置模板
ce/CE代码导读.md          按行号读源码
tools/probe.py           设备自检（测你的上下文/显存能喂多长）
docs/09-使用说明与设备自检.md
LICENSE                  AGPL-3.0
```

---

## 跑起来

```bash
# 1) 本地模型（llama.cpp / Ollama 等，OpenAI 兼容接口即可）
#    qwen3 一定要关思考，否则 content 是空的：
#    chat_template_kwargs={"enable_thinking": false}

# 2) 配置
cd ce
cp config.example.json config.json
#    改 read_roots（你能让它读的目录）、llama_url、model

# 3) 自检（先知道自己能喂多长）
python ../tools/probe.py

# 4) 启动
python ce_tool.py            # 默认 127.0.0.1:8092
curl http://127.0.0.1:8092/health
```

调用：

```bash
curl -X POST http://127.0.0.1:8092/task \
  -H 'Content-Type: application/json' \
  -d '{"task":"归拢 ~/notes 最近一天改过的文件，写份简报","session_id":"demo","stepwise":true}'
```

返回 `progress:{step,of,done,next}`——**没做完就再叫一次同 session**，它接着走。

## 它替你做了什么

| 小模型的病 | CE 的做法 |
|---|---|
| 上下文小，长文塞不下 | 按设备上限**分段喂**，每段各自提炼后合并 |
| 多步任务越做越飘 | **一步一提交**，步间只传摘要；最后一步出成品 |
| 爱编文件名 / 数字 | **代码守卫**：命中集核对 + 跨步数字一致 |
| 出错只能重来 | **每步检查点**，可回滚到第 N 步并追加新要求 |
| 死循环 | **熔断**：同动作 4 次停手 |
| 换台机器就爆 | **自检**测上限，写进配置，系统照算 |

## 工具标记（模型写，CE 真的做）

```
[查:关键词]      检索（关键词 / 语义，按设备自动降档）
[读:路径@N]      读文件（长文分段）
[归:目录@1]      归拢最近 N 天变动的文件
[记:内容]        写入外部系统
[搜笔:词]        在 Obsidian 笔记库搜（若装了 Obsidian）
[读笔:路径@N]    读某篇笔记
[日:内容]        追加到今天的日记
```

## 它不做什么

- 不承诺「意识」「情感」。
