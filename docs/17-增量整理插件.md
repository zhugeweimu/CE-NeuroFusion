# 17 · 增量整理插件（给文本工作者）

> 完整用法见包内 `plugins/ce_iterate/README.md`。这篇只讲它和 CE 的分工。

## 分工

```
CE      ：把长材料切小、取料、守卫、回滚（服务 :8092，只认 POST /task）
插件    ：扫描新文件、维护游标、分批、落盘（不碰上下文策略）
```

## 为什么单独做成插件

```
· 扫描/定时/游标是"调用方的活"，不该塞进 CE 内核
· 文本工作者的目录结构千差万别，CE 不该知道
· 插件出错不影响 CE；CE 升级不用动插件
```

## 最小用法

```bash
python plugins/ce_iterate/ce_iterate.py --roots "D:\笔记" --dry-run
python plugins/ce_iterate/ce_iterate.py --roots "D:\笔记" --out "D:\笔记\整理" --task "整理成要点"
```

## 它不做的事

```
不生成内容之外的决策（写什么由 --task 决定）
不删除任何文件
不跨批做全局推理（每批独立整理后拼接）
```
