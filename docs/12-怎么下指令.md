# 12 · 怎么下指令：给 CE 的任务怎么写

> CE 是**执行器**，不是许愿池。
> 它对「素材 + 可验收的交付物」很在行；对「帮我优化一下」「随便写点」无能为力——而且失败得很难看：拆不成块、每块空产出、最后拼一堆废话。

---

## 一、一句话原则

**给它正文，给它能拆的具体指令。**

```
正文   要处理的东西：文件路径 / 粘贴的原文 / 目录
指令   要交出什么：几样东西、什么形式、按什么分类、多少字
```

缺了正文，它只能凭记忆编（会被接地守卫抓住，但那是浪费）。
缺了可拆的指令，它拆不出块，等于退回单轮——你付了分步的成本，没得到分步的好处。

---

## 二、三段式模板

```
【素材】<路径 或 粘贴的原文>
【交付】① … ② … ③ …        （每项都是一个能独立完成的成品）
【约束】分类标准 / 格式 / 字数 / 不要什么
```

**例子（能拆）**

```
【素材】D:\笔记\本周
【交付】
  ① 列出本周新增或修改过的文件，按类型分组
  ② 每组统计数量
  ③ 写一份 5 行以内的周报
【约束】只算 .md 和 .py；不要罗列没改过的文件
```

**例子（不能拆，会翻车）**

```
帮我看看这周干了啥，随便总结一下
```

差别在哪：后者没有素材范围、没有交付物、没有验收标准。CE 只能猜，猜出来也没法验。

---

## 三、可拆 vs 许愿：对照表

| 许愿式 | 改写成可执行 |
|---|---|
| 帮我优化一下这个项目 | 列出 `ce/ce_tool.py` 里 3 处最长的函数，各给一句改进建议 |
| 总结一下这些文档 | 读 `docs/` 下所有 .md，按主题分 3 类，每类写 20 字摘要 |
| 随便写点东西 | 写一篇 300 字的说明，讲清 CE 的三种跑法差异 |
| 看看有没有问题 | 检查 `tests/` 里 5 个脚本，列出依赖本机路径的地方 |
| 帮我整理桌面 | 归拢 `D:\桌面` 最近 7 天的文件，按扩展名分到 4 个子目录 |

**判断标准（三条都满足才叫“可拆”）**

```
① 有名词：具体文件 / 目录 / 字段 / 分类名
② 有动词：列 / 统计 / 比较 / 改写 / 分到 / 摘出
③ 有验收：条数、字数、格式、分组方式
```

---

## 四、一次别塞太多

分步的每一块都要带同一份素材。**素材不变，块数越多越贵**：

```
3 块  × 素材 3000 字 ≈ 9000 字输入
9 块  × 素材 3000 字 ≈ 27000 字输入
```

**建议：一次任务 ≤ 3 个交付物。** 想要 10 样东西，分三次发，每次都能中途检查、中途回滚。

---

## 五、统合不满意怎么办

合并那一轮如果写得不好（太散、不像一份文档），**不要把整个任务重跑**——那样素材又要重新喂一遍。

正确做法：**把成品当素材，再喂一次，这次只给一条指令。**

```bash
curl -X POST http://127.0.0.1:8092/task \
  -H 'Content-Type: application/json' \
  -d '{
    "task": "把下面这份材料重写成一份连贯的周报，保留所有具体条目，不要新增内容",
    "session_id": "merge2",
    "source": "<把上一次的成品粘在这里>"
  }'
```

**为什么这样更好**：

```
重跑分步   素材重新取一遍、N 块重新生成 → 贵、且可能不如上次
单轮重写   只处理成品，一次调用 → 便宜、可控
```

而且这次是**单指令**（一个交付物），拆解器不会拆，直接单轮写。

## 六、常见失败与对号入座

| 现象 | 原因 | 怎么改 |
|---|---|---|
| `拆要求 1 块`（没拆开） | 指令里只有一个动作，或全是形容词 | 拆成 2–3 个可交付项 |
| 某块 `产出 0 字 / flags=空产出` | 那块的素材里没有相关内容 | 检查素材是否覆盖该要求 |
| 成品“接地不合格” | 提到的文件名在检索结果里没有 | 先把素材喂全，或让它自己 `[查:]` |
| 结果很散、像清单不像文章 | 合并是“拼接”而不是“统稿” | 用第五节的单轮重写 |
| 同一件事说了两遍 | 两个交付项内容重叠 | 拆分时避免交叉 |

---

## 七、给调用方（写代码的人）的两条

**① 有正文就传 `source`，别指望它自己去翻**

```json
{"task": "...", "source": "<原文>", "stepwise": true, "auto": true}
```

`source` 会被当作“共享素材，只准依据这里的内容”，比让它自己猜要准得多。

**② 要进度就用 `stepwise` 不带 `auto`**

```
一次一块 → 每块回来都能看 flags、能回滚
auto:true → 一次跑完，适合你不盯着的时候
```
