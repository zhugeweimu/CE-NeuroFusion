# 03 · 踩坑记录与代码地图

> 两个用途：① 遇到同样症状，查这里知道**修在哪**；② 想知道某段代码**干什么**，看文末的地图。

---

## 一、踩过的坑（症状 → 真因 → 修在哪 → 怎么验证）

### 1. 模型回话是空的

- **真因**：qwen3 把内容全写在 reasoning 里，content 字段为空
- **修在哪**：`call_model` 请求里带 `chat_template_kwargs.enable_thinking=false`；
  服务端不认这个字段时自动去掉重试。**CE 不会回退读 reasoning_content**——
  `content` 为空就是空，所以 qwen3 这类模型必须把思考关掉。
- **怎么验证**：问一句'1+1'，回答非空

### 2. 说了一个不存在的文件名

- **真因**：模型自由发挥，把记忆里的名字当证据
- **修在哪**：grounding_violations + grounding_fix：比对本轮 hits_get() 命中集，不合格拦下重写
- **怎么验证**：故意让它引用 docs/不存在.md，会被拦

### 3. 文件名对不上（明明存在）

- **真因**：模型在中文和英文之间插了空格（08-CE 缺口.md）
- **修在哪**：_nf：比对前去掉空格/连字符/点/下划线
- **怎么验证**：带空格的写法也能通过

### 4. 命中集越查越少

- **真因**：后一次检索把前一回的命中集覆盖了
- **修在哪**：do_tool 的 读/查/归 分支改为累加（dict.fromkeys 去重）
- **怎么验证**：先 [归:] 32 个再 [查:] 一次，日报里的文件名不再被判越界

### 5. 多开几个请求就互相串

- **真因**：服务器是 ThreadingHTTPServer，命中集/进度是模块级全局
- **修在哪**：hits_get / set_step_info / step_info：改用 threading.local
- **怎么验证**：3 个不同任务同时发，答案各归各的

### 6. 一改就崩：list 不可调用

- **真因**：新函数叫 hits()，被 do_tool 里的局部变量 hits 遮蔽
- **修在哪**：改名 hits_get()
- **怎么验证**：并发测试通过

### 7. 分步之后数字乱跳（17/15/14）

- **真因**：每块各自取料，后一次结果覆盖前一次事实清单
- **修在哪**：run_mapreduce：首次预取结果固化到 ch['facts']，后续每块共用；_save_one 持久化
- **怎么验证**：五块摘要里数字一致

### 8. 交付物是'摘要的摘要'

- **真因**：把每步都压成摘要，最后再用摘要合成
- **修在哪**：is_last：最后一块直接出成品；只有成品 < 40 字才退回合成
- **怎么验证**：成品 1705 字、有表格

### 9. 越做越飘，信息逐级衰减

- **真因**：串行咀嚼：步1摘要喂步2，步2摘要喂步3
- **修在哪**：run_mapreduce：原文作共享底座，每块各自去取料
- **怎么验证**：日志显示共享素材 5491 字，三块各自 197/345/303 字

### 10. 回滚了但旧内容又混进来

- **真因**：rollback 只截 notes，map 模式存在 parts 里
- **修在哪**：rollback：parts 也按 to_step 截断
- **怎么验证**：回滚前 parts=3 → 回滚后 parts=1

### 11. 回滚后拿旧资料答新要求

- **真因**：facts（预取的事实清单）没清
- **修在哪**：rollback：默认清 facts；source 按 source_from 区分，用户给的保留
- **怎么验证**：回滚后 facts 0 字，补充要求已注入

### 12. 熔断被空格标点绕过

- **真因**：key 只做 strip()，换个写法就是新动作
- **修在哪**：_arg_key：去空格/标点/引号、全角转半角、小写后再计数
- **怎么验证**：7 种变形归一化后只有 1 个键

### 13. 拆解出'执行步骤1'这种废话

- **真因**：模型拆的不是要求，是口号
- **修在哪**：_is_junk_ask + decompose_asks：整句元词/等于原文/自我指涉/扣词后实义字<3 全丢
- **怎么验证**：7 条人造 → 留 2 条真要求

### 14. 只说文件夹名就抓瞎

- **真因**：预取只认绝对路径
- **修在哪**：_resolve_hint + _roots_names：直接试 → 相对白名单根 → 根自身名字 → 下一层模糊匹配
- **怎么验证**：docs/她的桌面/日报/ce 都能解析

### 15. 长文件只读了前半截

- **真因**：读文件时按单请求预算截断，分段代码没机会触发
- **修在哪**：SOURCE_TOTAL（默认 6 万字）与分段分离：读全文，喂的时候 _segments 切
- **怎么验证**：18.8KB 文件素材 7697 字完整进入

### 16. 写文件把成品覆盖成进度提示

- **真因**：保存逻辑不区分 done
- **修在哪**：/task：step_info() 存在且 done=false 时直接不写文件
- **怎么验证**：第1、2次调用后目标文件仍是哨兵内容

### 17. 换台机器就爆上下文

- **真因**：参数写死
- **修在哪**：tools/probe.py 测 n_ctx/slots/显存/字-token 比 → capacity.json → plan_work 算总账
- **怎么验证**：无 capacity 时按 3000 字/串行保守跑

### 18. 报错看不懂（新手卡这）

- **真因**：异常直接 repr / traceback
- **修在哪**：friendly_err：连不上/超时/404/权限/端口占用 → 中文三步排查；已是人话则直接返回
- **怎么验证**：模型地址写错时给出'检查三件事'

### 19. 幽灵变量

- **真因**：检查点里用 dir() 探测一个从未赋值的变量
- **修在哪**：改 t_step = time.time() 真计时
- **怎么验证**：静态检查未定义名字为 0

### 20. 工具注册参数类型写错导致加载失败

- **真因**：llm_tool 参数类型不支持 integer
- **修在哪**：注册参数类型只写 int/number，不写 integer
- **怎么验证**：服务能加载、工具能调

### 21. 永久删文件，找不回来

- **真因**：Remove-Item -Recurse -Force 绕过回收站
- **修在哪**：tools 里用回收站方案（trash），项目纪律：删除先进回收站
- **怎么验证**：回收站里能找到

### 22. 文档里出现控制字符

- **真因**：shell heredoc 把 \a 解释成响铃符，'agent' 变成 'gent'
- **修在哪**：写文档用 write/edit 工具，不用带转义的内联脚本；出包前扫控制字符
- **怎么验证**：README 控制字符 0


### 23. 成品里出现根本没提过的文件名
- **真因**：map 模式的最终成品没走接地守卫（只有单轮路径和每块走了）
- **修在哪**：run_mapreduce 收尾处调用 grounding_violations(成品, task)
- **怎么验证**：纯净包 + 真模型联调，日志出现「成品被守卫拦下」

### 24. 守卫一拦，成品变成两个字
- **真因**：把 grounding_fix 的返回当正文；它是「重写」路径，重写只会给一句空话
- **修在哪**：成品不走重写——保留原文，末尾追加一行「这些名字没核对到出处」的警告
- **怎么验证**：成品 841 字且带警告，不再是 2 字

### 25. grounding_fix 返回元组被当成字符串
- **真因**：函数签名是 (answer, task, history) 且返回 (答案, 提示)
- **修在哪**：解包 _fixed, _ = grounding_fix(...)
- **怎么验证**：接口返回的 answer 是字符串而非数组

### 26. 幽灵变量骗过了静态检查
- **真因**：grounding_violations 里用了未定义的 hits，而别的函数里有同名局部变量，
  我那个简易静态检查（收集全局 Store 名字）就被骗过去了；只有真跑才炸
- **修在哪**：改为 hits_now
- **怎么验证**：端到端跑一次才会暴露——静态检查不够，必须真跑

## 三、读代码的顺序建议

1. `plan_work` → 先看它怎么算"这次要跑几轮"
2. `run_mapreduce` → 分步主流程（拆要求 → 取料 → 出块 → 合并）
3. `_prefetch` / `_resolve_hint` → 怎么替模型取原料
4. `grounding_violations` / `number_conflicts` → 两道守卫
5. `_save_ckpt` / `rollback` → 留档与回滚
