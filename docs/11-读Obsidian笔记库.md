# 11 · 读你的 Obsidian 笔记库（CE 原生）

CE 内置四个标记，直接读写 Obsidian 库。

## 库从哪来

Obsidian 自己把用过的库登记在 `%APPDATA%\obsidian\obsidian.json`。
CE 读这张表就知道你有哪几个库，库名取目录名，默认用"正在打开"的那个。

想换库/加库：`ce/config.json` 里

```json
{
  "obsidian_vaults": { "我的笔记": "E:/Notes/我的笔记" },
  "obsidian_default": "我的笔记",
  "obsidian_daily_dir": "日记"
}
```

手填的覆盖自动发现的同名库。

## 四个标记

| 标记 | 干什么 |
|---|---|
| `[搜笔:关键词]` | 库里搜，返回文件和片段（只准依据这些答） |
| `[搜笔:库名|关键词]` | 指定某个库 |
| `[读笔:路径@N]` | 读某一篇；长文用 `@1` 续读 |
| `[日:内容]` | 往今天日记追加（也可 `[日:2026-10-24|内容]`） |
| `[记:某某.md|内容]` | 目标带 .md/.txt 就写笔记库 |

## 安全规矩（代码保证）

```
① 路径锁在库内：拒 ..、拒盘符、拒 / 开头的绝对路径、拒跳出
② 只追加不覆盖：目标已存在就写在末尾
③ 单次写入 ≤ 2000 字
④ 原子写：先写 .tmp 再 replace，断电不留半截文件
⑤ 没有删除能力：故意不做
```

## 实测

```
发现库 4 个，默认「幕-记忆」
[搜笔:记忆]           → 命中 6 篇，列出路径与片段
[读笔:索引/全部.md]    → 读到正文
[搜笔:灵枢-记忆|首页]  → 跨库命中 1 篇
[日:...]              → 真写进 日记\2026-10-24.md
[读笔:../外面.md]      → 拒绝：不许跳出笔记库
```
