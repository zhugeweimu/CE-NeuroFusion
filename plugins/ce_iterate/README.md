# ce_iterate · 增量整理插件（给文本工作者）

> 你不必每篇都手动丢给模型。**写进目录就行，它自己扫新的，攒成一份整理稿。**
> 这是 CE 的配套插件：CE 负责把长材料切小、取料、守卫；插件负责定时、扫描、游标。

## 它解决什么

```
你每天/每周在同一个目录里写笔记、访谈、素材、草稿
  → 想汇总时，得自己挑文件、自己拼提示词、自己控长度
用这个：
  → 它记住上次处理到哪，只处理新的
  → 按 CE 的预算自动分批，不会一次塞爆上下文
  → 结果写成一份 markdown，放在你指定的目录
```

**适合**：写作者、编辑、研究助理、整理访谈/会议记录/资料卡的人。
**不适合**：需要跨全文推理的创作、精确计算、无人值守的关键流程（CE 本身也不保证这些）。

## 前置

```
1. CE 已跑起来（默认 http://127.0.0.1:8092，GET /health 返回 ok=true）
2. Python 3.9+（插件纯标准库，不用装依赖）
3. 一个能写东西的目录（你的素材目录）
```

## 用法（命令行，五行以内）

```bash
# 看一眼会处理哪些文件（不调模型、不花钱）
python ce_iterate.py --roots "D:\笔记" --dry-run

# 真跑：把新增笔记整理成要点，结果写到 D:\笔记\增量整理\
python ce_iterate.py --roots "D:\笔记" --out "D:\笔记\增量整理" \
    --task "把这些新增笔记整理成一份要点清单，每条一行，保留人名与日期"

# 攒一周：只处理最近 7 天
python ce_iterate.py --roots "D:\笔记" --since 7 --out "D:\笔记\周汇总"
```

## 参数

| 参数 | 说明 | 默认 |
|---|---|---|
| `--roots` | 要扫的目录，逗号分隔 | 必填 |
| `--out` | 结果写哪个目录（自动按时间命名） | 不写则不落盘 |
| `--task` | 整理要求，写清楚交付物 | 整理成要点清单 |
| `--since` | 只处理最近 N 天（可覆盖游标） | 用游标/近 7 天 |
| `--max-chars` | 每批材料上限（喂给 CE 的预算） | 6000 |
| `--hash` | 开内容指纹（更准，慢一点） | 关 |
| `--min-files` / `--min-bytes` | 变化少于这个数就不唤醒模型 | 1 / 200 |
| `--min-interval` | 距上次至少隔多少秒 | 0 |
| `--dry-run` | 只列文件，不调用模型 | — |
| `--probe-usn C:` | 探测 NTFS 变更日志能不能用 | — |

环境变量：`CE_BASE`（CE 地址，默认 8092）、`CE_TOKEN`（CE 配了 token 时用）。

## 它怎么判断"新文件"（四层，都有盲区）

```
① 签名     mtime + size 与上次记录比   —— 新增/编辑/追加
② 指纹     --hash 读前 4KB 算 sha1     —— 签名没变但内容变了
③ 游标     mtime > 上次时间            —— 首次运行/游标丢失
④ USN      NTFS 变更日志（需管理员）    —— 只做可用性探测
```

**已知盲区**（README 里写明，不藏着）：

```
· 不开 --hash 时，"mtime 和大小都没变、内容改了"检测不到
· 复制进来的文件会保留旧 mtime —— 有基线后按"路径没见过"算新，能覆盖
· 从目录移走的文件不产生"删除事件"
· 时钟回拨会被识别，退回"按签名比对"
```

## 安全边界

```
只读 --roots 下的文件；只写 --out 目录和根目录下的游标文件
不执行任何命令、不删文件
CE 那边还有 read_roots/write_roots 白名单兜底
```

## 游标

```
<roots[0]>/.ce_iterate_state.json
  原子写（临时文件 + replace），断电不会写坏
  删了它 = 从近 7 天重新扫
```

## 退出码与输出

```
正常：打印"扫描 N / 变化 M / 批 K / 唤醒=True|False"，结果落盘
CE 不可用：单批失败会中止并打印原因，不假装完成
```

## 定时跑（可选）

```
Windows 任务计划程序：
  程序   python.exe
  参数   D:\CE\plugins\ce_iterate\ce_iterate.py --roots "D:\笔记" --out "D:\笔记\增量整理"
  触发   每天 22:00
```

## 与 CE 的关系

```
CE       ：上下文压缩、取料、守卫、回滚（服务 :8092）
本插件   ：扫描、游标、分批、落盘（只调用 CE 的 POST /task）
```

**CE 不需要知道你的目录结构，插件不需要知道怎么切上下文。**
