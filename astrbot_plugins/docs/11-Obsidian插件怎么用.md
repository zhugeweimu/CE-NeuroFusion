# 11 · Obsidian 插件怎么用（连笔记库）

## 一、它是什么

让「幕」直接读写 Obsidian 笔记库：搜、读、追加、写日记、新建。

**它不假设你拿笔记库干什么**——存记忆、写工作日志、记读书笔记都行。
库在哪，它自己会找。

**和 `bridge/sync.py` 的关系：**

```
本插件            按需动手：要看某篇、往日记里记一句，直接读写
```



---

## 二、配置：默认什么都不用填

**自动发现**：Obsidian 把所有开过的库登记在
`%APPDATA%\obsidian\obsidian.json`，插件读这张表就知道你有哪几个库。
库名取目录名，默认用「正在打开」的那个。

所以：**装了 Obsidian、又在里面打开过一个库 → 什么都不用配。**

要手填（改名字、加不在登记表里的目录、指定默认库），把 `config.example.json`
复制成 `config.json` 放插件目录旁：

```json
{
  "vaults": { "我的笔记": "E:/Notes/我的笔记" },
  "default_vault": "我的笔记",
  "daily_dir": "日记",
  "max_write_chars": 2000,
  "max_read_chars": 1500,
  "search_limit": 8
}
```

手填的会**覆盖**自动发现的同名库。Windows 路径写 `E:/Notes/我的笔记` 或
`E:\\Notes\\我的笔记` 都行。

## 三、六个工具

| 工具 | 干什么 | 例子 |
|---|---|---|
| `obsidian_vaults` | 有哪些库、各多少篇 | 「我有哪些笔记库」 |
| `obsidian_search` | 搜内容，返回 `[[链接]]` + 上下文 | 「搜一下关于记忆的」 |
| `obsidian_read` | 读一篇（长文分页） | 「读 日记/2026-10-24.md」 |
| `obsidian_append` | 往末尾追加（不存在则新建） | 「往首页末尾记一句」 |
| `obsidian_daily` | 往今天日记追加 | 「今天记一笔：……」 |
| `obsidian_new` | 新建一篇（同名拒绝） | 「新建笔记《分步模式》」 |

## 四、安全闸（代码保证，不靠模型自觉）

```
① 路径锁在库内     拒 ..、拒盘符、拒 / 开头的绝对路径、拒跳出库
② 只追加不覆盖     append 永远写末尾；new 遇到同名直接拒绝
③ 写入上限         单次 ≤ 2000 字
④ 原子写           先写 .tmp 再 replace，断电不留半截文件
⑤ 搜索不扫垃圾     .obsidian/、.trash/、>512KB 跳过
⑥ 没有删除能力     故意不做——要删你自己在 Obsidian 里删
```

**最要紧的一条**：`append` 永不覆盖，旧内容一个字都不会被动。

## 五、和 CE 的联动（重点）

CE 不依赖这个 AstrBot 插件也能读写笔记库——它自带四个内联标记：

| 标记 | 干什么 |
|---|---|
| `[搜笔:关键词]` | 库里搜，返回文件与片段；可写 `[搜笔:库名|词]` 指定库 |
| `[读笔:路径]` | 读库里某一篇；长文用 `[读笔:路径@1]` 继续 |
| `[日:内容]` | 往今天日记追加（也可 `[日:2026-10-24|内容]`） |
| `[记:某某.md|内容]` | 目标带 .md/.txt 就写笔记库，只追加不覆盖 |

CE 侧的库发现跟插件一样：先读 Obsidian 登记表，再叠加 `ce\config.json` 里的
`obsidian_vaults` / `obsidian_default`。

```
Obsidian 笔记库  ←─ CE（[搜笔:] [读笔:] [日:] [记:]）   执行器干活时直接读写
                ←─ AstrBot 插件 obsidian（六个工具）    聊天时她也能读写
```

**两条路同一套规矩**：路径锁在库内、只追加不覆盖、写入 ≤2000 字、原子写。

## 六、验收怎么做的

插件侧用**临时笔记库**跑真文件操作（不碰你的真笔记）：

```powershell
python default-workspace\agent-neurofusion\tests\test_obsidian.py
```

23 项：路径安全、搜索（标题优先/正文带上下文/跳过 .obsidian）、读取（正文/不存在给相近建议）、
追加（不覆盖/末尾/不存在则新建）、日记、新建（同名拒/非法字符替换）、写入上限、坏库提示。
**通过 23 / 失败 0**。

CE 侧实测（本机真库）：

```
发现库 4 个：笔记本A、笔记库B、笔记库C、工作笔记；默认 工作笔记
[搜笔:项目]              → 命中 6 篇，列出路径与片段
[读笔:索引/全部.md]       → 读到正文（共 124 字）
[读笔:全部.md]           → 不存在，提示「相近：索引/全部.md」
[搜笔:笔记库B|首页]      → 跨库命中 1 篇
[日:...]                → 真写进 工作笔记\日记\2026-10-24.md（已核对）
[读笔:../外面.md]        → 拒绝：不许跳出笔记库
```

## 七、常见问题

**Q：会不会写乱我的笔记？**
不会覆盖。`append` 只在末尾加，带 `---` 和时间戳分隔；`new` 遇到同名拒绝。

**Q：能删笔记吗？**
**不能**，这个插件没有删除能力——故意的。

**Q：它能看到我的私人笔记吗？**
能读（这是用途），但只在登记表/config 里列出的库内，越界一律拒。

**Q：库路径换了/新开了一个库？**
新开库：CE 60 秒内自动认到；插件重载一下即可。路径变了自己改 `config.json`。
